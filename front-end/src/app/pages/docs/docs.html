Theory & design

How the lab thinks

2048 is a Markov decision process with a tiny action set and a noisy transition model (new 2/4 tiles after every move). That makes it a clean sandbox for comparing handcrafted search against learned value functions.

Environment

  • 4×4 board, actions = Up / Right / Down / Left
  • After a successful slide/merge, spawn 2 (p=0.9) or 4 (p=0.1)
  • Reward ≈ merge score; episode ends when no legal move remains
  • Observations for DQN: log₂-scaled board tensor

Agents

Heuristic — scores empties, snake/corner weights, smoothness, and monotonicity, then greedily picks the best one-ply move.

Expectimax — max node over actions, chance node over spawn locations/values; depth capped for interactive demos.

Double DQN — CNN Q-network, replay buffer, target net, ε-greedy during training; inference uses a saved checkpoint.

Experimentation

Monte Carlo bakeoffs (many seeded games) estimate score and max-tile distributions. DQN ablations vary learning rate, reward shaping (max-tile bonus), and network width.

Artifacts land in experiments/runs/ — metrics JSONL, summaries, and checkpoints you can load on the Try page.
